# Resolve an RDesk app directory or app.R path

Resolve an RDesk app directory or app.R path

## Usage

``` r
rdesk_resolve_app_script(app_dir = ".")
```

## Arguments

- app_dir:

  Path to an application directory or an `app.R` script.

## Value

A list with normalized `app_dir` and `app_script` paths.
