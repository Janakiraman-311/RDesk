# Build a Linux application bundle

Build a Linux application bundle

## Usage

``` r
rdesk_build_linux_app(
  app_dir,
  app_name,
  app_version = "1.0.0",
  out_dir = tempdir(),
  runtime_dir = NULL,
  prune_runtime = TRUE,
  portable_r_method = "extract_only",
  build_installer = FALSE,
  use_download = FALSE
)
```
